# حوار (Hiwar) — رفيقتك الذكية 🌸

رفيقة ذكاء اصطناعي داعمة لطالبات المرحلة الثانوية، تنظّم الدراسة والواجبات والاختبارات والعادات والمواعيد حول مواقيت الصلاة — بالمحادثة النصية والصوتية.

## المميزات
- 👤 **حسابات مستخدمين**: تسجيل/دخول آمن (كلمة مرور مشفّرة scrypt) وملف شخصي يتزامن عبر الأجهزة.
- 💬 **المحادثة هي الواجهة**: كل شيء يتم بالحوار — أسئلة ذكية + أزرار اختيار سريعة + أوامر نصية.
- 🕌 **جدول يراعي الصلاة**: يحسب مواقيت الصلاة (طريقة أم القرى) حسب مدينتك، ويبني جدولاً يومياً متوازناً.
- 🏫 **إعداد أولي**: المدينة (مع اقتراح الخبر) + المدرسة (الثانوية الثامنة بجدولها الجاهز أو مدرسة أخرى) + الصف والشعبة.
- 📚 **المهام الدراسية**: واجبات ومشاريع واختبارات لكل مادة، مع الموعد والمدة، وترتيب حسب الأولوية.
- 📅 **مناسبات ودورات** + 😴 **نوم وعناية شخصية وتجهيز الحقيبة**.
- ⭐ **تتبع العادات**: قرآن/مذاكرة/رياضة… مع سلاسل إنجاز ورسائل تحفيزية.
- ⏰ **تذكيرات**: قبل المهام بـ15 دقيقة + تذكير النوم والعادات والصلاة، مع نغمات ناعمة وإشعارات.
- 🎙️ **محادثة صوتية كاملة**: استماع (كلام→نص) + نطق بشري فصيح بالحركات (Google TTS) أو نطق الجهاز دون إنترنت.
- 🧠 **تخصيص ذكي**: يتعلم أوقات إنجازك ويقترح تحسينات ويشجعك.
- 🛡️ **إصلاح ذاتي**: حارس يعيد تشغيل الخادم، قاطع كهربائي، تحويل تلقائي بين النماذج، ووضع طوارئ محلي.

## البنية
| الجزء | الوظيفة | التقنية |
|---|---|---|
| `server.js` | الخادم + الذكاء + النطق + الإصلاح الذاتي | Node.js (بلا اعتماديات) |
| `companion.js` (الخادم) | الحسابات + الملف الشخصي + مواقيت الصلاة | Node.js + crypto |
| `guard.js` | الحارس الذاتي | Node.js |
| `public/` | الواجهة والمنطق الأمامي | HTML/CSS/JS |
| `data/` | تخزين الحسابات والملفات (تُنشأ تلقائياً) | JSON |

## التشغيل محلياً
يتطلب Node.js 18+. ضع مفتاح Gemini في ملف `.env`:
```
GEMINI_API_KEY=AQ.Ab...
```
ثم:
```bash
npm start
# افتح http://localhost:3000
```
> `npm start` يشغّل الحارس الذاتي. وللخادم مباشرة: `npm run start:server`.

## النشر الدائم
اقرأ **[DEPLOY.md](DEPLOY.md)** — نشر بضغطة واحدة على Glitch أو Render مع وضع `GEMINI_API_KEY` في متغيرات البيئة.

## الأمان
- كلمات المرور مشفّرة (scrypt + ملح عشوائي).
- مفتاح API يعيش في الخادم فقط (متغير بيئة) ولا يصل للمتصفح إطلاقاً.
- `data/` و`.env` محذوفان من Git والحزمة.
